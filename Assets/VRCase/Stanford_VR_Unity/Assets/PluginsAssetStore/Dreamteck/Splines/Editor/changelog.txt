----- 1.0.73 -----
FEATURE: Greatly improved GC performance

FIX: Updated the code to fit the API changes in Unity 5.6

API: Spline.Evaluate no longer uses the "ref" keyword for the samples array - it's not needed
API: Added a new overload to SplineUser.Evaluate - public void Evaluate(SplineResult result, double percent). It's used to reduce GC
API: Added a new overload to SplineUser.Project - public void Project(SplineResult result, Vector3 point) It's used to reduce GC
API: Added a new overload to SplineResult.Lerp - public static void Lerp(SplineResult a, SplineResult b, double t, SplineResult target). It's used to reduce GC
API: Renamed the "Absorb" method of SplineResult to "CopyFrom"

----- 1.0.72 -----
FIX: Multithreading now works properly for the ExtrudeMesh component
FIX: Fixed ArgumentOutOfRange exceptions when baking meshes in some cases
FIX: The Bake Mesh Window and the Bake Tool now prevent the user from saving OBJ files outside of the project folder - an action that produces errors
FIX: PluginInfo displaying a black window and throwing a NullReferenceException has been fixed
FIX: Fixed SplineUsers returning two identical samples when sampling a SplineComputer with only one control point
FIX: The Operations dropdown in the editor scene view has been moved to the left on Mac in order to avoid Retina display issues
FIX: Inserting spline points with the "Add Node" now works properly and produces a smooth spline
FIX: Fixed SplineFollower.GetNextNode returning wrong results
FIX: Fixed the SplineFollower.GetNextNode getting the wrong node
FIX: Fixed ParticleController component incompatibility with versions 5.1, 5.2 and 5.3 of Unity
FIX: Fixed the scene GUI flickering when the user is flying through the scene with the WASD buttons and the cursor is outside the scene view
FIX: Right and left simultaneous mouse click over a spline point no longer causes the editor to freeze
FIX: SplineFollower.onEndReached and SplineFollower.onBeginningReached are now called after the transformation is applied

FEATURE: Baked meshes now go through an optimization process

----- 1.0.7 -----

FIX: Fixed the ArgumentOutOfRange exception when the spline is in Linear mode without any control points and "Create Point" mode is on
FIX: Fixed the building problem with Windows Store apps - WSA don't support multithreading
FIX: Fixed point update when the the Presets & Primitives window is used (broken in 1.0.6)
FIX: Fixed the ArgumentOutOfRange exception in the Editor when a SplineUser is set to sample another SplineUser
FIX: Spline points properly update when Undo/Redo is performed
FIX: The Dreamteck folder can now be moved in another folder without Dreamteck Splines losing its resource paths
FIX: Briging down the resolution of the SplineFollower to zero no longer throws an exception
FIX: The custom editor GUI now properly initializes through a static constructor
FIX: Fixed the clip range on the SplineUser class not updating properly when clip values are set to 0 and 1
APIL All scripts' line endings have been converted to UNIX (LF)

FEATURE: Optimizing meshes has been removed as an option from the MeshGenerator classes due to Mesh.Optimize() being removed from Unity 5.5
FEATURE: Added a public ResampleTransform method to the SplineComputer class which forces the computer to immediately resample its transform
FEATURE: Added a physics mode to the SplineFollower for working with 2D and 3D Rigidbodies
FEATURE: Applying position, rotation and scale in the SplineFollower and SplinePositioner is now done per axis
FEATURE: Added the capsule primitive
FEATURE: Added the rounded rectangle primitive
FEATURE: Added custom rotation fields to the SplineFollower and SplinePositioner components
FEATURE: Added cap meshes to the ExtrudeMesh component
FEATURE: Added multiple meshes to the ExtrudeMesh component (Ordered and Random iterations).
FEATURE: Added round caps to the tube generator
FEATURE: Created a precise scene view editor for the clip range of the SplineUser
FEATURE: The Level Terrain tool now has a clip range for the spline
FEATURE: Added an Update components tool which forces all or certain components in the scene to be rebuilt

API: Renamed SplineFollower.startPercent to SplineFollower.startPosition
API: Renamed SplineFollower.findStartPoint to SplineFollower.autoStartPosition
API: Added a motion property to the SplineFollower and SplinePositioner to control how the transformation is being applied
API: Added an offsettedPositionResult property to the SplinePositioner which returns the spline sample with applied offsets.
API: Added a CalculateLength method to the SplineUser class
